A profile of the surface, not an engine: there is nothing to run behind the conversation, because the conversation is the work. It also needs a different privacy treatment from every other page here.

```loop
companion
```

**State.** Private cross-session notes: themes, what matters, what moved. Mis-routing *into* this profile changes how the conversation is handled.
**Rails.** No tools by default beyond private notes, one question at a time, and never manufacture a completion.
**Exits.** None. The user leads away, or a task emerges and task dominance moves it to that task's shape.
**Handoffs.** To `transact` when a real-world need surfaces, as the user chooses.

> [!WARNING]
> **Who can read this.** An assistant that remembers your therapy is not the same product as one that logs your errands. Where do companion notes live, and who can read them?

> [!QUESTION]
> **Safety edges.** What does this loop do when the conversation turns into something a friend cannot hold alone?
