# Getting started

Start with one thing you would like a hand with. You do not need to connect every account or have a whole plan ready.

## 1. Create your account and space

Use **Create your companion** on the landing page to enter early-access signup. Account setup provisions your workspace before you can use it. An existing account without a workspace resumes setup; a ready account opens Mission Control. Installations without Clerk signup use the existing workspace-credential login instead.

You can start with platform model defaults or provide supported model credentials during setup. Additional setup and release availability depend on the deployment; signup does not promise instant access or a particular setup duration.

## 2. Choose or create an assistant

Use **Settings → Personas** in the web app to create a named assistant, describe how it should help, and select it for new conversations. Existing conversations keep their addressed identity. Several assistants can live in one account's workspace, with distinct instructions and memory banks; workspace services and connected accounts may be shared.

## 3. Start a conversation

Open **Chat**. Bring a question, a decision or work to prepare. For example: “Help me decide what to look for in my next laptop” or “I prefer short, practical check-ins.” Context can be retained and used later; remembering is not a promise of perfect recall.

Goals, plans, routines and reminder records have client-specific surfaces. The native iPhone/iPad goal tracker uses Life Engine records; the web app does not automatically have every native screen.

## 4. Connect what you need

Use **Connections** for supported accounts and tools when you need them. Access depends on each integration. Read what the connection authorizes and keep the scope appropriate to the task. You do not need to connect an account to understand the product or have a conversation.

## 5. Review the help

Use supported memory views, recorded audit activity, and the result of delegated work to understand what happened. Respond to configured approval or input requests. Proactive and notification experiences have separate rollout status; a static example is not an active schedule or real notification.

For information boundaries, see [Isolation](/docs/architecture/isolation). Customer-managed encryption keys, universal deletion/export controls and independent computers per assistant are not current promises.
