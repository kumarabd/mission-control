# Mission Control

Implementation repository for Mission Control, a project-management board for discovering projects and viewing their planning state with links to canonical sources.

## Repository layout

- `AGENTS.md` — implementation-session instructions and canonical documentation ownership.
- `apps/webapp/` — reserved source location for the browser application.

The selected frontend stack is React, strict TypeScript, TanStack Query, and Zustand. Application code, dependencies, and build/test commands have not been initialized yet; tooling selection is part of W0 in the canonical plan.
